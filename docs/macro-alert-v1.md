# 宏观仓位风险预警 v1

宏观页的仓位风险预警是一个市场级、确定性、可审计的试运行规则。它回答的
不是“哪天一定下跌”，而是“哪些可验证条件同时出现后，应当开始人工复核风险
预算”。系统不读取个人持仓，不给出卖出比例，也不会执行订单。

## 产品边界

- 美股与 A 股分别判断；一个市场的压力不能直接把另一个市场升级为清仓审查。
- 状态固定为“观察 → 减仓准备 → 减仓候选 → 防御 / 清仓审查”。
- 新闻、KOL 热度、LLM 解读、黑天鹅模板概率只作解释背景，不能改变状态。
- 任一核心数据缺失、陈旧或出现未来时间戳时，当前状态为
  `observe + abstain`；这表示证据不足，不表示风险较低。
- 所有阈值均为待走步回测的试运行参数，不是市场规律或收益保证。

## 当前采集证据

每次宏观采集会并发读取六个月日线，只在快照中保留最近完成收盘的派生值：

- 美股趋势：SPY 收盘、SMA20、SMA60、SMA20 五日斜率、五日变化与 60 日回撤。
- A 股趋势：沪深 300 的同一组指标。
- 波动率：VIX 完成日线。VIX 衡量标普 500 未来约 30 天的隐含波动率，
  不预测市场方向，不能单独触发行动。
- A 股汇率压力：USD/CNY 水平与五日变化同时判断。
- 系统性金融压力：美国金融研究办公室 OFR FSI；正值表示高于历史平均，
  官方数据通常滞后约两个工作日。

日线优先由 Yahoo Finance Chart 接口提供；若沪深 300 数据过期或不可用，
采集器会切换到腾讯行情的固定 `sh000300` 日线，不会猜测或替换成其他指数。
OFR FSI 来自
[OFR 官方页面](https://www.financialresearch.gov/financial-stress-index/)。
VIX 定义与限制见 [Cboe VIX FAQ](https://www.cboe.com/tradable_products/vix/faqs)。
上线前后应继续核验数据提供方的可用性和展示许可。

## 试运行状态机

完成日线少于 60 条、最后一个完成收盘超过 5 个自然日、OFR 复用旧值，或
OFR 观测超过允许时效，均不能升级。

美股初始条件：

- 趋势确认：SPY 收盘低于 SMA20，且 SMA20 五日斜率为负。
- 严重趋势：SPY 低于 SMA60、SMA20 低于 SMA60、60 日回撤不低于 10%。
- 压力线：VIX 28 / 35；OFR FSI 2 / 5。

A 股初始条件：

- 趋势确认与美股相同；严重回撤初值为 12%。
- 汇率压力：USD/CNY 至少 7.20 且五日升幅至少 0.5%；严重线为 7.30
  且五日升幅至少 1%。
- VIX 与 OFR 只作为全球压力支柱；A 股清仓审查还必须包含人民币汇率压力。

升级规则：

1. 一个领先压力信号，或减仓原始条件首次出现：`prepare_reduce`。
2. 趋势确认与至少一个独立压力支柱连续两个不同收盘日共振：
   `reduce_candidate`。
3. 严重趋势与两个独立严重压力支柱连续确认，且此前至少已进入减仓候选：
   `exit_candidate`。界面固定显示为“防御 / 清仓审查”。

宏观任务每小时运行，但同一收盘日重复运行不会增加确认次数。风险条件解除也
需要两个不同收盘日确认，减少红黄灯来回跳变。

## 后续校准

固定阈值上线后只能标记为试运行。正式校准应采用滚动历史分位数和走步验证，
至少记录提前量、误报率、状态持续时间、换手与最大回撤。后续可在取得稳定、
可合法使用的数据源后，加入 VIX 期限结构、信用利差、NFCI、DR007、公开市场
操作、融资余额和市场广度；这些新增支柱也必须由确定性规则计算，不能交给
LLM 直接修改行动。

本功能仅用于研究和风险复核，不构成投资建议。股市有风险，投资需谨慎。
